# Background Removal Project

## Description
This project removes the background from images using AI-based segmentation.

## Features
- Remove background from images
- Batch processing
- Web-based interface

## Technologies Used
- Python
- OpenCV
- RemBG
- Flask

## Setup Instructions

1. Clone repository
2. Create virtual environment:
   python -m venv venv

3. Activate:
   venv\Scripts\activate

4. Install dependencies:
   pip install -r requirements.txt

## Run Project

For CLI:
python main.py

For Web App:
python app.py

## Output
Processed images are saved in output/ or downloaded via browser.
